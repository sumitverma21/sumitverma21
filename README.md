## 🚀 Featured Projects

### [Samyukt](https://github.com/sumitverma21/Samyukt) — Intelligent VCS Platform
> *B.Tech Final Year Project · Sep 2026*

A next-generation version control system with AI-powered conflict resolution and real-time collaboration.

- **3-Layer Merge Engine** — Text-level (LCS diff) → Structural (AST) → Semantic AI (85% confidence threshold → auto-merge)
- **Real-time collaboration** — Yjs CRDT over Socket.io, live cursors, zero-conflict editing
- **Git-style file storage** — SHA1 content-addressable blobs, FileTree snapshots per commit
- **CLI tool** — `samyukt init/add/commit/push/pull/branch/merge/log/diff/rollback`
- **GitHub feature parity** — Fork, tags, releases, inline review comments, full-text search, contributors graph
- **Stack:** React 19 · Node.js · Express 5 · MongoDB · Socket.io · Yjs · Docker · Nginx · JWT · Jest
